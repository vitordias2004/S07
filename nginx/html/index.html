Nginx + Jenkins + Pipeline Mail

Painel publico das notificacoes enviadas pela pipeline

Este Nginx agora tem uma funcao visivel no projeto: servir um painel com o historico dos e-mails que o Jenkins enviou apos cada execucao. A pagina consome um arquivo JSON compartilhado entre os containers e mostra o status da build, o horario do envio e os destinatarios mascarados.

Como esse fluxo funciona

A pipeline envia o e-mail com o `script-email.js` e, logo depois, registra um resumo do envio em uma pasta compartilhada. O Nginx expoe essa pasta como conteudo estatico para a turma conseguir validar visualmente a trilha de notificacoes.

Jenkins Executa checkout, build da imagem, testes Cypress, empacotamento, push e notificacao.
script-email.js Envia o e-mail real e grava um resumo do envio com build, status, horario e destinatarios mascarados.
Nginx Serve este painel e o JSON compartilhado em `nginx/html/data/email-history.json`.
Atualizacao automatica O painel recarrega o historico a cada 30 segundos, sem precisar reiniciar os containers.
